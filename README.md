# Hemorrhage Stroke Analysis: Active Learning, Human-in-the-Loop and Data Augmentation Approach

## Overview

This project focuses on the detection (classification) and segmentation of brain hemorrhages in Computed Tomography (CT) scans. The primary goal is to demonstrate how **Active Learning (AL)** and **Human-in-the-Loop (HITL)** techniques can reduce the reliance on large volumes of labeled data while maintaining or improving Deep Learning model performance.

This repository contains complete pipelines for:
1.  **Data Preprocessing:** Converting raw CT slices into training-ready formats.
2.  **Classification:** Comparing baseline models (EfficientNetB0) against Uncertainty-based Active Learning approaches.
3.  **Segmentation:** Comparing U-Net architectures (Standard, VGG16, ResNet50) and Active Learning cycles for precise lesion segmentation.

## Dataset
The dataset used in this project is the Computed Tomography (CT) Images, available on Kaggle.

**Download:** https://www.kaggle.com/datasets/vbookshelf/computed-tomography-ct-images

**Setup Instructions:**
1. Download the dataset from the link above.
2. Extract the contents into a folder named `Patients_CT` in the root directory of this project.

**Important:** The `Patients_CT` folder is used exclusively by the `Split-data.py` script. All subsequent training scripts use the `train/` directory, which is automatically generated by the split script.

## Usage & Execution Order
To replicate the experiments, the scripts must be executed in the following strict order:

1. Data Preparation (`Split-data.py`)
  - Reads the raw dataset from `Patients_CT`.
  - Resizes images and masks to 512x512.
  - Normalizes and splits the data, creating the `train/` directory.

2. Baseline Classification (`classification.py`)
  - Trains an EfficientNetB0 model for binary classification (Hemorrhage vs. Healthy).
  - Uses K-Fold Cross-Validation and final evaluation on a hold-out test set.

3. Active Learning Classification (`classification-al-hitl.py`)
  - Simulates a HITL scenario where the model starts with a small labeled pool.
  - Iteratively queries the most uncertain samples to be labeled and added to the training set.

4. Baseline Segmentation (`segmentation.py`)
  - Trains and compares three U-Net architectures: Base U-Net, U-Net with VGG16 encoder, and U-Net with ResNet50 encoder.
  - Evaluates metrics such as Dice Coefficient, IoU, Sensitivity, and Specificity.

5. Active Learning Segmentation (`segmentation-al.py`)
  - Applies Active Learning cycles to the segmentation task using a U-Net (VGG16), selecting regions with the highest uncertainty.

## Results & Computational Resources
Due to the high computational complexity of the classification and segmentation models and the iterative nature of Active Learning cycles, these scripts were executed on a computer with the following specifications: CPU Intel i9-11900KF, 64GB of RAM, and GPU Nvidia RTX 3080Ti 12 B, due to the high complexity of the neural networks used.

The `Results/` directory included in this repository contains the terminal logs and training histories generated during these runs. This allows for the analysis of performance metrics without the need to re-train the heavy models on standard hardware, which might be computationally infeasible.
